# Credit Card Fraud data

Place the standard dataset here as:

```
ml/data/creditcard.csv
```

Download: Kaggle “Credit Card Fraud Detection” (284,807 rows, columns Time,V1..V28,Amount,Class).

Do NOT commit the full CSV if repo size is a concern — pipeline will error with a clear message until it exists.
Run: `python ml/run_pipeline.py`
